EEMI — Formation Python

Scripting Python assisté par IA

5 exercices pour découvrir Python en utilisant l'IA comme outil de développement

Ces exercices ont deux objectifs : découvrir les bases de Python et apprendre à travailler avec une IA pour produire du code. Pour chaque exercice, lisez l'objectif, rédigez votre propre prompt, puis soumettez-le à l'IA de votre choix (ChatGPT, Claude, Copilot…). Votre travail est ensuite de comprendre le code produit, de le tester, et de corriger ce qui ne va pas.

1
Rédigez votre prompt et soumettez-le à l'IA
2
Copiez le code dans un fichier .py et exécutez-le
3
Testez les cas listés — notez ce qui marche ou pas
4
Corrigez en retournant à l'IA si nécessaire

Les exercices

1
Calculateur d'IMC
variables · conditions · input()
Objectif
Le script demande le poids (en kg) et la taille (en mètres) d'une personne, calcule son IMC et affiche la catégorie correspondante : sous-poids, poids normal, surpoids ou obèse. Il doit gérer les erreurs si l'utilisateur saisit une valeur non numérique.
Cas à tester
  • 80 kg / 1.80 m → poids normal
  • 50 kg / 1.75 m → sous-poids
  • 100 kg / 1.65 m → obèse
  • Entrer "abc" à la place d'un chiffre
  • Entrer 0 pour la taille
2
Analyseur de texte
strings · split() · boucles
Objectif
Le script demande à l'utilisateur de saisir un texte, puis affiche trois informations : le nombre de mots, le nombre de caractères (sans les espaces), et le mot qui apparaît le plus souvent. La casse ne doit pas avoir d'importance ("Le" et "le" comptent comme le même mot).
Cas à tester
  • Texte normal avec répétitions
  • Texte avec majuscules mélangées
  • Texte vide (juste Entrée)
  • Un seul mot
  • Texte avec ponctuation
3
Générateur de mots de passe
fonctions · import random · paramètres
Objectif
Le script génère un mot de passe aléatoire selon les préférences de l'utilisateur : longueur souhaitée, inclusion ou non de chiffres, inclusion ou non de caractères spéciaux. Le code doit être organisé sous forme de fonction.
Cas à tester
  • Longueur 12, chiffres oui, spéciaux oui
  • Longueur 8, que des lettres
  • Longueur 0 ou négative
  • Générer 5 mots de passe à la suite
  • Vérifier qu'ils sont tous différents
4
Liste de tâches persistante
fichiers · listes · boucles · menus
Objectif
Le script est un gestionnaire de tâches en ligne de commande avec un menu interactif. Il doit permettre d'ajouter une tâche, lister les tâches (avec leur statut fait/à faire), marquer une tâche comme faite, et quitter. La liste doit être sauvegardée dans un fichier pour persister entre deux exécutions.
Cas à tester
  • Ajouter 3 tâches, quitter, relancer → tâches toujours là
  • Marquer une tâche déjà faite
  • Entrer un numéro de tâche inexistant
  • Afficher quand la liste est vide
  • Entrer une option de menu invalide
5
Analyse d'un journal SSH : qui attaque le serveur ?
fichiers · split() · dictionnaires · détection
Objectif
Vous êtes au SOC. Le serveur srv-web-01 a été attaqué cette nuit et on vous confie son journal d'authentification : seances/s2-parsing-journaux/donnees/auth-ex5.log.extrait (données fictives). Le script lit ce fichier (son chemin est donné en argument) et affiche un rapport :
  • le nombre de lignes analysées et le nombre d'échecs de connexion (Failed password) ;
  • le top 5 des adresses IP en échec, avec leur nombre d'échecs ;
  • les IP qui dépassent un seuil d'échecs (10 par défaut, modifiable) : brute force ;
  • les IP qui ont essayé au moins 5 noms d'utilisateur différents : password spraying ;
  • surtout : les connexions réussies (Accepted) depuis une IP qui avait échoué avant. C'est le signe d'une compromission possible.
Le script ne doit jamais planter, même sur une ligne abîmée.

Conseil : commencez par ouvrir le fichier et lire 30 lignes à la main. Un bon prompt décrit le format des lignes à l'IA.
Cas à tester
  • Le fichier fourni : quelle IP attaque le plus ?
  • Trouver l'IP qui a fini par réussir à se connecter : avec quel compte, et qu'a-t-elle fait juste après ?
  • Repérer l'IP qui essaie beaucoup de comptes, lentement
  • Une adresse IPv6 est dans le fichier : est-elle comptée ?
  • Le fichier contient une ligne tronquée et une ligne vide
  • Fichier inexistant, fichier vide
  • Seuil à 5, puis à 50

Rendu attendu : pour chaque exercice, déposez votre fichier .py final et un court commentaire (3-5 lignes) expliquant ce que vous avez dû corriger ou ajuster par rapport au code initial produit par l'IA.
