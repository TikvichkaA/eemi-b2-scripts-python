## Démarrer les exercices

```bash
git fetch origin
git merge origin/main --no-edit
cd seances/s2-parsing-journaux/exercices-python
python3 ex01_uptime.py     # vérifie l'exercice 1
python3 bilan.py           # bilan des 8 exercices
```

Consignes, modes d'usage de l'IA et prompts à copier : **[`exercices-python/guide-exercices.html`](exercices-python/guide-exercices.html)**, à ouvrir dans un navigateur.

Mémo de référence : [Python express](../s1-scripter-admin/python-express.html).

À rendre (pousser sur votre branche) : vos fichiers `exNN_….py` et au moins 3 entrées dans `JOURNAL-IA.md`.
