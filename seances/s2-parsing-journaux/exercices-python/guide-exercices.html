Séance 2 · Apprendre Python avec l'IA comme tuteur

8 petits exercices Python

Huit fonctions courtes, de plus en plus riches, qui mènent tout droit au détecteur de brute force SSH. Chaque exercice se vérifie tout seul, et chacun vous fait utiliser l'IA d'une façon différente : on apprend à s'en servir pour comprendre, pas seulement pour produire.

≈ 100 min Individuel, entraide autorisée Non noté 3 entrées de journal IA

0 · Démarrer

Récupérez d'abord les nouveaux fichiers du cours dans votre branche :

git fetch origin
git merge origin/main --no-edit
cd seances/s2-parsing-journaux/exercices-python

Chaque exercice est un fichier exNN_….py. La consigne est en haut du fichier, la fonction à écrire au milieu, les tests en bas. Pour vérifier :

python3 ex01_uptime.py      # ✓ ou ✗ pour chaque cas, avec l'attendu et l'obtenu
python3 bilan.py            # le bilan des 8 exercices
Ne modifiez que la fonction

Ne touchez pas aux tests en bas du fichier (sauf à l'exercice 5, où l'on vous demande d'en ajouter). Ne renommez pas les fichiers : l'exercice 7 importe les exercices 4 et 6.

La règle de l'oral

À tout moment, l'intervenant peut vous demander d'expliquer n'importe quelle ligne de vos fichiers. Une ligne que vous ne savez pas expliquer compte comme non faite, même si les tests passent.

Le prompt « tuteur »

À coller en début de conversation avec l'IA de votre choix. Il change sa façon de répondre pour toute la suite.

Je débute en Python et je fais un exercice pour apprendre.
Règles pour toute la conversation :
- ne me donne PAS la solution complète, sauf si je l'écris explicitement « donne la solution » ;
- quand je montre du code, dis-moi ce qui ne va pas et pourquoi, avec un indice ;
- explique simplement, avec un petit exemple à taper dans l'interpréteur python3 ;
- si j'utilise un mot de travers, corrige-moi.
Contexte : Python 3.12, Linux, bibliothèque standard uniquement.
1

Formater une durée · ex01_uptime.py

Objectif. formater_uptime(90061) → "1j 1h 1min". Notions : //, %, f-string.

Mode IA : seul d'abord. Cinq minutes sans IA. Si un test échoue, copiez le message ✗ et votre fonction à l'IA (avec le prompt tuteur) : « pourquoi ce test échoue ? »

Indice

Essayez dans python3 : 90061 // 86400, puis 90061 % 86400. Le reste, c'est ce qu'il reste à répartir en heures et minutes.

2

Lire « clé=valeur » · ex02_cle_valeur.py

Objectif. 'PRETTY_NAME="Ubuntu 24.04.1 LTS"' → ("PRETTY_NAME", "Ubuntu 24.04.1 LTS"). Notions : partition, strip, renvoyer deux valeurs.

Mode IA : seul d'abord. Puis faites expliquer votre erreur.

Indice

Le dernier test a un = dans la valeur. Comparez dans l'interpréteur "a=b=c".split("=") et "a=b=c".partition("=").

3

Ports en écoute · ex03_ports.py

Objectif. ["0.0.0.0:22", "[::]:22", "0.0.0.0:80"] → [22, 80] : triés, en entiers, sans doublon. Notions : listes, set, sorted, int.

Mode IA : expliquer, pas écrire. Exemple de demande :

Sans me donner le code de la fonction : comment récupérer ce qui est après
le DERNIER « : » dans une chaîne comme "[::]:22" ? Et comment enlever les
doublons d'une liste ? Donne-moi juste les noms des méthodes et un mini-exemple.
4

Compter des occurrences · ex04_compter.py

Objectif. ["a", "b", "a"] → {"a": 2, "b": 1}, sans collections.Counter. Notions : dictionnaire, get.

Mode IA : l'IA écrit, vous expliquez. Demandez-lui la fonction (dites « donne la solution »), collez-la, puis écrivez au-dessus de chaque ligne un commentaire # … qui l'explique avec vos mots.

Pourquoi cet exercice compte

Ce motif « compter avec un dictionnaire » est le cœur du détecteur de brute force : il revient à l'exercice 7 et dans le TP2.

5

Comptes humains · ex05_comptes.py

Objectif. À partir de lignes de /etc/passwd, la liste des comptes avec UID ≥ 1000 (sauf 65534) et un shell interactif. Les lignes cassées sont ignorées. Notions : split(":"), int, conditions, continue.

Mode IA : l'IA propose des tests. Une fois au vert :

Voici ma fonction et ses tests. Propose 3 cas limites (des lignes de
/etc/passwd inhabituelles) qui pourraient la faire échouer, avec le
résultat attendu pour chacun. N'écris pas de code de correction.

Ajoutez les 3 cas dans la liste des tests, sous le commentaire prévu. Si l'un échoue, corrigez votre fonction.

Piège

int("x") plante avec ValueError. Une ligne mal formée peut avoir 7 champs mais un UID qui n'est pas un nombre.

6

L'IP d'un échec SSH · ex06_ip_echec.py

Objectif. L'IP d'une ligne Failed password …, None sinon. Notions : in, split(), index, None.

Mode IA : comparer deux solutions.

Donne-moi deux versions de cette fonction : l'une avec split(), l'autre
avec une expression régulière (module re). Pour chacune : avantages,
inconvénients, et un cas où elle se tromperait.

Gardez celle que vous savez expliquer, et notez dans JOURNAL-IA.md pourquoi. Les regex sont au programme de la suite de la séance : la comparaison vous servira.

7

Top des IP · ex07_top_ip.py

Objectif. Lire donnees/auth.log.extrait et renvoyer les n IP qui ont le plus d'échecs : [("203.0.113.45", 22), …]. Fichier absent → []. Notions : lire un fichier, import, sorted avec key.

Mode IA : piloter. Prompt structuré, à compléter :

Contexte    : Python 3.12, bibliothèque standard. J'ai déjà deux fonctions :
              compter(liste) -> dict et ip_echec(ligne) -> str | None.
Tâche       : écrire top_ip(chemin, n) qui lit un fichier de log et renvoie
              les n IP avec le plus d'échecs, en liste de couples (ip, nombre).
Contraintes : réutiliser mes deux fonctions ; égalité → ordre alphabétique ;
              fichier absent → liste vide, sans planter.
Demande     : explique chaque ligne, en particulier le tri.

Puis passez la réponse à la grille des 5 questions de la charte avant de la coller.

Bravo si vous êtes ici

Vous venez d'écrire le cœur d'un détecteur de brute force SSH : c'est la base du TP2.

8

Bonus · Déboguer · ex08_seuil.py

Objectif. Le code fourni contient deux erreurs. Trouvez-les et corrigez-les. Notions : try/except, raise, types.

Mode IA : déboguer. Lancez le fichier, puis :

Voici une fonction et la sortie de ses tests. Explique-moi pourquoi les
tests échouent, sans corriger le code à ma place.
Indice

Regardez le type de ce qui est renvoyé ('80' ou 80 ?), et ce que fait le bloc except : un script d'administration doit-il deviner une valeur quand l'entrée est fausse ?

Le journal IA : 3 entrées minimum

Dans JOURNAL-IA.md, à la racine de votre branche. Choisissez trois exercices aux modes différents. Pour chacun :

  • le prompt utilisé (copié tel quel) ;
  • ce que l'IA a bien fait, et ce qu'elle a fait de travers ou d'inutile ;
  • ce que vous avez appris, en une phrase.
