Python : 34 petits exercices pour se lancer

Des exercices de quelques lignes, du plus simple au plus riche. Chacun a un indice et une solution à déplier, avec le résultat attendu. Cochez au fur et à mesure : la progression reste dans votre navigateur.

5 à 10 min par blocAucune installationSolutions cachées

Comment travailler

  1. Blocs A à D : dans l'interpréteur. Tapez python3 dans le terminal, puis vos lignes ; exit() pour sortir.
  2. Blocs E à G : dans un fichier essais.py, lancé avec python3 essais.py. Les blocs sur plusieurs lignes y sont plus faciles à écrire.
  3. Essayez avant de déplier. Puis l'indice. La solution en dernier, et comparez-la à la vôtre : il y a souvent plusieurs bonnes réponses.
  4. Bloqué par une erreur ? Lisez la dernière ligne du message, puis demandez à l'IA de l'expliquer (pas de corriger à votre place).
L'indentation compte

Après un : (if, for, while, def), les lignes du bloc sont décalées de 4 espaces. Dans l'interpréteur, validez un bloc par une ligne vide.

A · Premiers pas

Tapez python3 dans le terminal, puis essayez directement. exit() pour sortir.

Calculatrice

Combien y a-t-il de minutes dans une journée ? Et de secondes ?

Indice

24 heures, 60 minutes par heure : une multiplication suffit.

Solution et résultat attendu
print(24 * 60)
print(24 * 60 * 60)

Résultat :

1440
86400

B · Les chaînes de caractères

Une chaîne, c'est du texte entre guillemets. On peut la mesurer, la découper, la transformer.

B1

Mesurer et crier

Avec nom = "srv-web-01", affichez sa longueur, puis le nom en majuscules.

Indice

len(…) et la méthode .upper().

Solution et résultat attendu
nom = "srv-web-01"
print(len(nom))
print(nom.upper())

Résultat :

10
SRV-WEB-01
B2

Premier, dernier, morceau

Toujours avec nom = "srv-web-01" : affichez le premier caractère, le dernier, puis seulement web.

Indice

On compte à partir de 0. nom[-1] est le dernier. nom[début:fin] découpe un morceau (fin exclue).

Solution et résultat attendu
nom = "srv-web-01"

print(nom[-1])
print(nom[4:7])

Résultat :

s
1
web
B3

Découper une ligne

Avec ligne = "alice:x:1000:1000", découpez sur les :. Affichez la liste obtenue, puis seulement l'UID (le 3e champ).

Indice

1000

D · Les dictionnaires

Un dictionnaire associe une clé à une valeur, entre accolades. C'est la forme du JSON.

D1

Décrire un serveur

Créez serveur avec les clés nom ("srv01"), ip ("10.0.0.5") et ram (8). Affichez son IP.

Indice

{"nom": "srv01", …}, puis serveur["ip"].

Solution et résultat attendu
serveur = {"nom": "srv01", "ip": "10.0.0.5", "ram": 8}
print(serveur["ip"])

Résultat :

10.0.0.5
D2

Modifier, ajouter

Passez la RAM à 16, ajoutez une clé os valant "Ubuntu", et affichez le dictionnaire.

Indice

Même syntaxe pour modifier et pour ajouter : serveur["cle"] = valeur.

Solution et résultat attendu
serveur = {"nom": "srv01", "ip": "10.0.0.5", "ram": 8}
serveur["ram"] = 16
serveur["os"] = "Ubuntu"
print(serveur)

Résultat :

{'nom': 'srv01', 'ip': '10.0.0.5', 'ram': 16, 'os': 'Ubuntu'}
D3

Parcourir

Affichez chaque clé et sa valeur, une par ligne, sous la forme nom : srv01.

Indice

for cle, valeur in serveur.items():

Solution et résultat attendu
serveur = {"nom": "srv01", "ip": "10.0.0.5"}
for cle, valeur in serveur.items():
    print(f"{cle} : {valeur}")

Résultat :

nom : srv01
ip : 10.0.0.5
D4

Une clé absente

Avec ce même serveur, essayez serveur["disque"] : que se passe-t-il ? Puis obtenez 0 à la place, sans erreur.

Indice

serveur.get("disque", 0) renvoie 0 si la clé n'existe pas.

Solution et résultat attendu
serveur = {"nom": "srv01", "ip": "10.0.0.5"}
# serveur["disque"]  → KeyError
print(serveur.get("disque", 0))

Résultat :

0

F · Les fonctions

Une fonction a un nom, reçoit des valeurs et en renvoie une avec return.

F1

Le carré

Écrivez carre(n) qui renvoie n × n. Affichez carre(7).

Indice

def carre(n): puis return …

Solution et résultat attendu
def carre(n):
    return n * n

print(carre(7))

Résultat :

49
F2

Pair ou impair

Écrivez est_pair(n) qui renvoie True si n est pair. Testez avec 4 et 7.

Indice

Un nombre est pair si le reste de sa division par 2 vaut 0 : n % 2 == 0.

Solution et résultat attendu
def est_pair(n):
    return n % 2 == 0

print(est_pair(4))
print(est_pair(7))

Résultat :

True
False
F3

Avec une valeur par défaut

Écrivez en_alerte(pct, seuil=80) qui renvoie True si pct atteint le seuil. Testez en_alerte(85) et en_alerte(85, 90).

Indice

seuil=80 dans les parenthèses donne une valeur par défaut.

Solution et résultat attendu
def en_alerte(pct, seuil=80):
    return pct >= seuil

print(en_alerte(85))
print(en_alerte(85, 90))

Résultat :

True
False
F4

La moyenne

Écrivez moyenne(valeurs) qui renvoie la moyenne d'une liste, et 0 si la liste est vide. Testez avec [10, 20, 30] et [].

Indice

sum(…) / len(…), mais diviser par 0 plante : testez d'abord if not valeurs:.

Solution et résultat attendu
def moyenne(valeurs):
    if not valeurs:
        return 0
    return sum(valeurs) / len(valeurs)

print(moyenne([10, 20, 30]))
print(moyenne([]))

Résultat :

20.0
0

G · Petits défis

On combine tout. Essayez sans l'IA, puis demandez-lui d'expliquer votre erreur si vous bloquez.

G1

Compter les voyelles

Comptez les voyelles du mot "administrateur".

Indice

Une boucle sur chaque lettre, et if lettre in "aeiouy":.

Solution et résultat attendu
mot = "administrateur"
nb = 0
for lettre in mot:
    if lettre in "aeiouy":
        nb += 1
print(nb)

Résultat :

6
G2

Palindrome

Un mot est un palindrome s'il se lit pareil dans les deux sens. Testez "kayak" et "python".

Indice

mot[::-1] renvoie le mot à l'envers.

Solution et résultat attendu
for mot in ["kayak", "python"]:
    print(mot, mot == mot[::-1])

Résultat :

kayak True
python False

Pour chaque ligne : split(":"), puis le premier élément.

lignes = ["root:x:0:0", "alice:x:1000:1000", "bob:x:1001:1001"]

G4

Compter les services

Avec connexions = ["ssh", "http", "ssh", "dns", "ssh"], construisez un dictionnaire qui compte chaque service.

Indice

Un dictionnaire vide, puis comptes[s] = comptes.get(s, 0) + 1 dans une boucle.

Solution et résultat attendu
connexions = ["ssh", "http", "ssh", "dns", "ssh"]
comptes = {}
for s in connexions:
    comptes[s] = comptes.get(s, 0) + 1
print(comptes)

Résultat :

{'ssh': 3, 'http': 1, 'dns': 1}
