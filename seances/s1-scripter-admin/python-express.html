1 · Lancer Python

L'interpréteur interactif : pour essayer une ligne.

$ python3

Un script : un fichier lancé du début à la fin.

$ python3 inventaire.py --help

# tester une seule fonction du TP :
$ python3 -c "import inventaire; print(inventaire.infos_cpu())"
L'indentation fait partie du code

Pas d'accolades ni de fi/done : un bloc commence après : et se compose des lignes décalées de 4 espaces. Un décalage incohérent donne IndentationError. Réglez votre éditeur pour insérer des espaces, pas des tabulations.

4 · Chaînes de caractères B1 · B4 · B6 · B8

ligne = 'PRETTY_NAME="Ubuntu 24.04.1 LTS"'

ligne.startswith("PRETTY_NAME=")    # → True
cle, _, valeur = ligne.partition("=")  # coupe au premier "="
valeur                              # → '"Ubuntu 24.04.1 LTS"'
valeur.strip('"')                   # → 'Ubuntu 24.04.1 LTS'   retire les " au bord

"MemTotal:   8127920 kB".split()   # → ['MemTotal:', '8127920', 'kB']   coupe sur les espaces
"alice:x:1000:1000::/home/alice:/bin/bash".split(":")
                                    # → ['alice', 'x', '1000', '1000', '', '/home/alice', '/bin/bash']
"/bin/bash".endswith(("nologin", "false"))  # → False
"  texte \n".strip()                # → 'texte'   retire espaces et retour à la ligne

Les f-strings : un f devant les guillemets, des variables entre { }.

nom, pct = "/var", 86
f"{nom} est plein à {pct} %"        # → '/var est plein à 86 %'
f"{'Nom':<9}: srv01"                # → 'Nom      : srv01'   aligné à gauche sur 9
f"{pct:>3} %"                       # → ' 86 %'              aligné à droite sur 3

6 · Dictionnaires B2 · B3 · B4 · B6 · B10

Des paires clé → valeur. C'est ce que renvoient presque toutes les fonctions du TP, et c'est exactement la forme du JSON.

hote = {"nom": "srv-web-01", "noyau": "6.8.0-45-generic"}
hote["nom"]                # → 'srv-web-01'
hote["uptime_s"] = 1049000 # ajoute une clé
hote.get("absent", 0)      # → 0    valeur par défaut si la clé manque (pas d'erreur)
hote["absent"]             # → KeyError !

for cle, valeur in hote.items():
    print(cle, valeur)

import json
print(json.dumps(hote, ensure_ascii=False, indent=2))   # dict → texte JSON

7 · Conditions et boucles partout

for ligne in lignes:
    if not ligne:              # ligne vide → on passe à la suivante
        continue
    champs = ligne.split(":")
    uid = int(champs[2])
    if uid >= 1000 and uid != 65534:
        print(champs[0])
    elif uid == 0:
        print("root")
    else:
        pass                   # « ne rien faire »

0 <= seuil <= 100              # comparaison chaînée, pratique pour B9

Opérateurs : == égal, != différent, and, or, not (en toutes lettres, pas && ni ||).

8 · Fonctions tous les TODO

def infos_cpu() -> dict:
    """Ce texte est la documentation de la fonction."""
    coeurs = os.cpu_count()
    charge = [round(x, 2) for x in os.getloadavg()]
    return {"coeurs": coeurs, "charge": charge}
  • def nom(paramètres): déclare la fonction ; return renvoie le résultat.
  • -> dict et chemin: Path sont des annotations : elles documentent le type attendu, Python ne les vérifie pas. Gardez-les.
  • Dans le squelette, chaque TODO se termine par un return {} ou return [] provisoire : remplacez-le par le vrai résultat.
  • [round(x, 2) for x in …] est une compréhension de liste : une boucle qui construit une liste en une ligne. Une boucle for + append fait la même chose.

9 · Lire un fichier B1 · B2 · B4 · B5 · B6

from pathlib import Path

texte = Path("/proc/meminfo").read_text()   # tout le fichier dans une chaîne
for ligne in texte.splitlines():            # une ligne à la fois, sans le "\n"
    print(ligne)

# Variante classique, utile pour les gros fichiers :
with open("/etc/passwd", encoding="utf-8") as f:
    for ligne in f:
        print(ligne.rstrip())

Dans le squelette, le fichier à lire arrive souvent en paramètre (chemin, mounts) : utilisez ce paramètre, pas le chemin écrit en dur. C'est ce qui permettra de tester la fonction avec un faux fichier en séance 5.

10 · Erreurs et exceptions B1 · B5 · B7 · B10

Lire un message d'erreur : par le bas.

Traceback (most recent call last):
  File "inventaire.py", line 72, in lire_meminfo
    total = valeurs["MemTotal:"] // 1024
TypeError: unsupported operand type(s)
for //: 'str' and 'int'

Dernière ligne : quoi. Au-dessus : où (fichier, ligne, fonction).

Rattraper une erreur prévisible :

try:
    texte = chemin.read_text()
except OSError:          # fichier absent, droits…
    return "inconnu"

try:
    usage = shutil.disk_usage(point)
except OSError as e:
    log.debug("ignoré %s : %s", point, e)
    continue

12 · Méthode pour avancer sans se noyer

  1. Une fonction à la fois. Écrivez-la, puis testez-la seule : python3 -c "import inventaire; print(inventaire.lire_meminfo())".
  2. Essayez la ligne difficile dans l'interpréteur avant de l'écrire dans le fichier.
  3. Affichez ce que vous manipulez : un print(champs) temporaire répond à la moitié des questions. Retirez-le ensuite : la sortie JSON doit rester propre.
  4. Lisez l'erreur par le bas, et regardez le numéro de ligne.
  5. Demandez à l'IA d'expliquer, pas seulement d'écrire : « explique-moi ligne par ligne ce que fait ce code ». C'est une bonne entrée de JOURNAL-IA.md.
