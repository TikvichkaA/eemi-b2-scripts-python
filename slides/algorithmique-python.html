DéfinitionUn algorithme, c'est quoi ?

Une suite finie d'instructions précises qui transforme des entrées en un résultat.

Entrées

Une recette de cuisine est un algorithme. Un programme, c'est un algorithme écrit dans un langage qu'une machine sait exécuter.
Algorithmique et Python2

Les briquesTout algorithme se construit avec 5 briques

  1. Des données, rangées dans des variables : nombres, textes, listes…
  2. La séquence : faire une chose, puis la suivante
  3. Le choix : faire ceci si une condition est vraie
  4. La répétition : refaire la même chose pour chaque élément, ou tant que c'est nécessaire
  5. Le découpage : regrouper des étapes sous un nom (une fonction) pour les réutiliser
Ces briques existent dans tous les langages. Apprendre à les combiner, c'est l'essentiel ; la syntaxe vient après.

VariablesUne variable, c'est une étiquette sur une valeur

seuil = 10          # on colle l'étiquette « seuil » sur 10
echecs = 0
echecs = echecs + 1 # on lit, on ajoute 1, on range

print(echecs)       # 2

Ce n'est pas une équation

x = x + 1 est absurde en maths, mais normal en programmation : calculer à droite, ranger à gauche.

= range une valeur ; == compare deux valeurs.

Un bon nom de variable explique ce qu'elle contient : nb_echecs plutôt que n, ip_source plutôt que x.

Structures de donnéesRanger plusieurs valeurs

Liste

ips = ["10.0.0.1",
       "10.0.0.2"]

Des valeurs dans l'ordre, repérées par leur position (à partir de 0).

Dictionnaire

echecs = {"10.0.0.1": 3}
echecs["10.0.0.1"]

Des paires clé → valeur. Idéal pour compter ou décrire un objet.

Ensemble

vues = {"10.0.0.1"}

Des valeurs uniques, sans ordre. Idéal pour dédoublonner.

Choisir la bonne structure, c'est la moitié de l'algorithme : « compter par IP » appelle un dictionnaire.

Le choixSi… alors… sinon

Pseudo-code

SI pct >= 90 ALORS
    afficher "CRITIQUE"
SINON SI pct >= 80 ALORS
    afficher "ALERTE"
SINON
    afficher "OK"
FIN SI

Python

if pct >= 90:
    print("CRITIQUE")
elif pct >= 80:
    print("ALERTE")
else:
    print("OK")
L'ordre des tests compte : avec pct = 95, seule la première condition vraie est exécutée. Inversez les deux tests et 95 % donnera « ALERTE ».
Algorithmique et Python9

La répétitionDeux sortes de boucles

Pour chaque élément

for ligne in lignes:
    if "Failed" in ligne:
        print(ligne)

On sait sur quoi on boucle : une liste, un fichier, un dictionnaire. C'est la boucle la plus courante.

Tant que

essais = 0
while essais < 3:
    essais += 1
    print("tentative", essais)

On boucle tant qu'une condition est vraie : relancer, attendre, réessayer.

Boucle infinie : un while dont la condition ne devient jamais fausse. Ici, oublier essais += 1 suffit.
Algorithmique et Python10

Le découpageLes fonctions

Pseudo-code

FONCTION est_echec(ligne)
    RENVOYER "Failed password"
             est dans ligne
FIN FONCTION

Python

def est_echec(ligne: str) -> bool:
    return "Failed password" in ligne
  • Une fonction a un nom, des entrées (paramètres) et une sortie (return)
  • Elle fait une seule chose, qu'on peut tester seule
  • Un gros problème = plusieurs petites fonctions qui s'appellent
  • On l'écrit une fois, on l'utilise partout

Algorithmique et Python12

MéthodeDu problème au code, en 5 étapes

  1. Comprendre : quelles entrées, quel résultat ? Faire un exemple à la main, sur 5 lignes.
  2. Décomposer : quelles sous-tâches ? (lire, filtrer, extraire, compter, trier)
  3. Écrire le pseudo-code, en français, sans se soucier de la syntaxe
  4. Traduire en Python, une fonction à la fois
  5. Tester : un cas normal, un cas vide, un cas bizarre
C'est aussi la bonne façon de travailler avec une IA : vous lui donnez les étapes 1 à 3, elle aide pour la 4, et vous faites la 5.

Les classiquesTrois motifs qu'on retrouve partout

Compter

total = 0
for l in lignes:
    if est_echec(l):
        total += 1

Un accumulateur qui part de 0.

Chercher le maximum

pire = None
for ip, n in echecs.items():
    if pire is None or n > echecs[pire]:
        pire = ip

On garde le meilleur vu jusqu'ici.

Chercher un élément

trouve = False
for ip in liste_noire:
    if ip == ip_source:
        trouve = True
        break

On s'arrête dès qu'on a trouvé.

Python fournit des raccourcis (sum, max, in), mais il faut savoir ce qu'ils font : ce sont ces boucles.

Exemple completDétecter un brute force SSH

Pseudo-code

compteurs ← dictionnaire vide
POUR CHAQUE ligne DU fichier
    SI la ligne est un échec ALORS
        ip ← l'adresse après "from"
        compteurs[ip] ← compteurs[ip] + 1
    FIN SI
FIN POUR
POUR CHAQUE (ip, nb) DANS compteurs
    SI nb >= SEUIL ALORS
        signaler ip
FIN POUR

Python

SEUIL = 10
compteurs = {}
with open("auth.log") as f:
    for ligne in f:
        if "Failed password" in ligne:
            mots = ligne.split()
            ip = mots[mots.index("from") + 1]
            compteurs[ip] = compteurs.get(ip, 0) + 1

for ip, nb in compteurs.items():
    if nb >= SEUIL:
        print(f"ALERTE {ip} : {nb} échecs")
