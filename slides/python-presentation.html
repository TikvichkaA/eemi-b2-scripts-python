Carte d'identitéPython, c'est quoi ?

  • Un langage de programmation généraliste, créé par Guido van Rossum
  • Première version en 1991 ; le nom vient des Monty Python, pas du serpent
  • Python 3 depuis 2008 ; Python 2 est abandonné depuis 2020
  • Une nouvelle version chaque automne : 3.15 en octobre 2026
  • Libre et gratuit, géré par la Python Software Foundation

Sa philosophie

Beautiful is better than ugly.
Simple is better than complex.
Readability counts.

Extraits du « Zen of Python » : tapez import this dans python3.

Pourquoi luiPourquoi Python est partout

Ses atouts

  • Lisible : proche de l'anglais, peu de symboles
  • « Piles incluses » : plus de 200 modules livrés avec
  • PyPI : plus de 900 000 bibliothèques à installer
  • Tourne sur Linux, Windows, macOS, sans modification

Où on le trouve

  • Administration et automatisation
  • Données et intelligence artificielle
  • Web : API, sites, outils internes
  • Sécurité : analyse, détection, outillage
Contrepartie : il est plus lent que C ou Go. Pour un script d'administration, ça ne compte presque jamais.

La syntaxeTout Python de base, sur une slide

import json                          # utiliser un module

seuil = 80                           # une variable
disques = {"/": 47, "/var": 86}      # un dictionnaire

def en_alerte(pct: int) -> bool:     # une fonction
    return pct >= seuil

alertes = []                         # une liste
for point, pct in disques.items():   # une boucle
    if en_alerte(pct):               # une condition
        alertes.append(point)
        print(f"ALERTE {point} : {pct} %")

print(json.dumps(alertes))           # ["/var"]
  • Pas de ;, pas d'accolades
  • Les blocs se font par l'indentation (4 espaces), après un :
  • Pas de type à déclarer : Python le déduit
  • # commence un commentaire

ChoisirBash ou Python ?

Bash si…

  • on enchaîne des commandes existantes
  • le script tient en quelques lignes
  • pas de données structurées

Python si…

  • il faut découper, compter, trier des données
  • on lit ou produit du JSON, du CSV, une API
  • il faut gérer proprement les erreurs et tester
  • le script va grossir
Dans la vraie vie, on fait les deux : un script Bash qui appelle un script Python est très courant.
