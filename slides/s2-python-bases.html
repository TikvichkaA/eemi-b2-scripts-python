ChaînesDécouper une ligne : 80 % du travail d'admin

ligne = "alice:x:1000:1000:Alice:/home/alice:/bin/bash"
champs = ligne.split(":")      # ['alice', 'x', '1000', '1000', 'Alice', '/home/alice', '/bin/bash']
champs[0]                      # 'alice'      on compte à partir de 0
int(champs[2])                 # 1000

'ID="ubuntu"'.partition("=")   # ('ID', '=', '"ubuntu"')   coupe au premier =
'"ubuntu"'.strip('"')          # 'ubuntu'
"Failed password" in ligne     # False
"/bin/bash".endswith("bash")   # True

pct = 86
print(f"/var est plein à {pct} %")   # f-string : les variables entre { }
C'est l'équivalent de cut, grep et echo, sans lancer de commande.

CollectionsListes et dictionnaires

Liste : une suite ordonnée

ips = ["203.0.113.45", "10.0.0.12"]
ips.append("203.0.113.45")
len(ips)                 # 3
ips[0]                   # premier
sorted(set(ips))         # sans doublon, trié

Dictionnaire : clé → valeur

hote = {"nom": "srv01", "coeurs": 4}
hote["nom"]              # 'srv01'
hote["ram"] = 7937       # ajouter
hote.get("disque", 0)    # 0 si absent
for cle, val in hote.items():
    print(cle, val)
Un dictionnaire, c'est exactement la forme d'un objet JSON. C'est ce que renvoient presque toutes nos fonctions.

ContrôleConditions et boucles

for ligne in lignes:
    if not ligne:          # ligne vide
        continue           # → suivante
    champs = ligne.split(":")
    uid = int(champs[2])
    if uid >= 1000 and uid != 65534:
        print(champs[0])
    elif uid == 0:
        print("root")
  • == égal, != différent
  • and, or, not en toutes lettres
  • for x in … parcourt une liste, un fichier, un dictionnaire
  • continue passe au tour suivant, break sort de la boucle
  • 0 <= x <= 100 : comparaison chaînée
S2 · Python avec l'IA8

FonctionsLe motif qu'on utilisera tout le module

def compter(elements: list) -> dict:
    """Compte les apparitions de chaque élément."""
    comptes = {}
    for e in elements:
        comptes[e] = comptes.get(e, 0) + 1
    return comptes

compter(["a", "b", "a"])   # {'a': 2, 'b': 1}
  • def nom(paramètres): puis un bloc
  • return renvoie le résultat
  • : list, -> dict : annotations, pour documenter
  • Une fonction = une tâche, qu'on teste seule
Ce compter est le cœur du détecteur de brute force : compter les échecs par IP.

Apprendre avec l'IACopier ne fait pas apprendre

Ce qui ne marche pas

  • coller l'énoncé, coller la réponse
  • les tests passent… et on ne sait rien faire
  • au premier oral ou à la première panne, on est bloqué

Ce qui marche

  • lui demander d'expliquer une erreur
  • lui demander un indice, pas la solution
  • lui faire écrire, puis expliquer soi-même chaque ligne
  • lui demander des tests, ou de comparer deux solutions
Règle du jour : je peux vous demander d'expliquer n'importe quelle ligne de vos fichiers.
